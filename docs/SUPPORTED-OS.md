# Supported Operating Systems

## Initial support matrix

| OS | Target | Installation path | Current maturity |
|---|---:|---|---|
| Ubuntu Server | 24.04 LTS class | systemd source installer | MVP target |
| Debian | current stable class | systemd source installer | MVP target |
| Windows 10 | supported configurations | PowerShell source installer | MVP; service pending |
| Windows 11 | supported configurations | PowerShell source installer | MVP; service pending |

## Architectures

- amd64 / x86_64
- arm64 / aarch64 target

Exact tested versions and benchmark hardware should be added to release notes as CI/hardware validation expands.
